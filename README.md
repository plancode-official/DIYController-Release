## ✨ المميزات الرئيسية (Key Features)

1. **واجهة عائمة تكتيكية بدون إطارات (Frameless Floating UI):**
   - تصميم حديث ومبسط مستوحى من RemoteXY؛ أزرار ومفاتيح ومحركات وعصا تحكم تطفو بسلاسة فوق خلفية الشاشة بدون أي إطارات أو صناديق كرتونية مربكة.

2. **فتح فوري بدون انتظار (0ms Instant Cache):**
   - بمجرد جلب المخطط من المتحكم لأول مرة، يُحفظ تلقائياً على هاتفك ليفتح التطبيق بمشروعك في 0 ثانية فور تشغيله مع مزامنة الحالات في الخلفية.

3. **لا حاجة لقواعد بيانات أو سيرفر خارجي:**
   - مخطط التحكم مضمن بالكامل داخل كود C++ المرفوع على المتحكم (`PLANCODE_UI_JSON`). يقوم المتحكم نفسه بتزويد التطبيق بواجهته.

4. **دعم شامل لبروتوكولات الربط:**
   - 📶 **واي فاي مباشر (WiFi AP / SoftAP):** الاتصال بنقطة البث الخاصة بالمتحكم (مثل `192.168.4.1`) والتحكم برمشة عين.
   - 🌐 **واي فاي منزلي (WiFi LAN):** التحكم عبر الشبكة المحلية بـ IP محلي.
   - 🔵 **بلوتوث (Bluetooth BLE & Classic SPP):** اقتران فوري عبر خدمات البلوتوث المدمجة.
   - 🔌 **كابل USB OTG / Serial:** تحكم سلكي مباشر فائق السرعة يدعم لوحات Arduino Uno و Mega و Nano.
   - ☁️ **ربط سحابي اختياري:** عبر منصة بلان كود السحابية.

5. **المتحكمات واللوحات المدعومة:**
   - **ESP32** (جميع الطرازات: NodeMCU, WROOM, ESP32-S3, ESP32-C3)
   - **ESP8266** (NodeMCU, Wemos D1 Mini)
   - **Arduino** (Uno, Nano, Mega مع موديلات HC-05 / HM-10 أو كابل OTG)
   - **Raspberry Pi Pico W**
